# Breast Cancer Prediction

A Machine Learning project that analyzes tumour measurements and predicts whether a breast tumour is **Benign (B)** or **Malignant (M)**.

## Project Overview

The objective of this project is to build a classification model using machine learning techniques to predict breast cancer diagnosis based on numerical tumour features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset

- 569 records
- 30 numerical features
- Target: Diagnosis (Benign / Malignant)

Dataset file: `data/brca.csv`

## Project Workflow

1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Feature scaling
6. Model training
7. Model evaluation

## Project Files

- `breast_cancer_prediction.ipynb` – Jupyter Notebook containing the complete ML workflow.
- `data/brca.csv` – Dataset used for model training and evaluation.

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells sequentially.
3. The dataset is loaded from this repository.
